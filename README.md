## GITHUB USERS APP

A flutter application that displays Github Users all over the world when searched by location or username.

## Introduction

GitHub Users App is used to search for  GitHub Users all over the world either by location or by username. It fetches the data from the Github API and displays it according to the user's desired format of search.
The application is structured using Clean Architecture hence easy scalability and maintenance.

## Features
- Search: Search for GitHub users all over the world either by location or username.  
- Pagination: Infinite scroll feature to retrieve more users as user scrolls through the provided lists. 
- User Details: View detailed info about a specific user selected from the list provided when searched.
- Share profile: Tap the share button on the user details page to share the user profile displayed to different platforms.
- Internet connectivity: Notify users when they have no internet connection.
- Clean Architecture: Code is structured in layers to help in maintainability and scalability.

## Usage

Once you run the app, use the search fields to find Git Hub users either by location or username. 
Tap on a user in the list provided to see their details and use the share button to share the profile if you would like to. 
All these features will work when your device is connected to the internet and if there is no internet connection then you will be notified.
